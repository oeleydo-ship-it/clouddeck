Uplary — Self-Hosted Server Control Plane & SaaS Hosting Panel

Uplary is a complete Laravel-based platform for selling managed hosting or running your own DevOps control plane. Connect DigitalOcean or any Ubuntu VPS, auto-provision servers, and deploy Laravel, WordPress, and React (Vite SPA) applications — with Stripe billing, teams, monitoring, backups, and SSL built in.

Think Laravel Forge or Cloudways, but you own the code and can white-label it for your agency or SaaS business.

Why Uplary?

  • Launch your hosting SaaS — subscription plans, Stripe Checkout, quotas, feature flags
  • Three deployment platforms — Laravel zero-downtime Git deploy, WordPress, React/Vite SPA
  • Full server lifecycle — provision, deploy, SSL, cron, queues, firewall, backups
  • Modern React console — Inertia.js + React 19, live deployment logs, dark UI
  • Web installer — no manual database seeding; create admin at /install
  • 80+ automated tests — production-quality codebase

Installation (summary)

  1. Upload files; point web root to public/
  2. composer install --no-dev
  3. cp .env.example .env && php artisan key:generate
  4. php artisan migrate
  5. npm ci && npm run build
  6. Visit /install — create super-admin
  7. Start Horizon + scheduler (see INSTALLATION.md)
